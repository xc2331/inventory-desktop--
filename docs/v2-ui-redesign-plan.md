# 家庭物资管家 V2 UI 重设计规划

## 1. 目标与原则

1. **交互体验优先**：减少点击层级，关键操作一步触达。
2. **视觉美观**：统一配色、圆角、阴影、动效，建立高级感。
3. **功能扎实**：在现有功能稳定基础上做体验升级，不堆砌新功能。
4. **体积可控**：便携版打包尽量小，避免引入过重依赖。

## 2. 当前问题诊断

- 界面偏朴素，信息密度不均。
- 卡片 hover 动效单一，缺少反馈层次。
- 侧边栏、顶部栏占用了较多固定空间。
- 没有主题切换（浅色 / 深色）。
- 打包产物体积还有优化空间。

## 3. 设计方向

### 3.1 视觉语言

- **配色**：保留 emerald 为主色，引入中性灰阶（slate/stone 50-950），增加一种强调色（amber 用于过期预警，rose 用于库存不足）。
- **圆角**：卡片 16px、按钮 10px、输入框 8px，保持统一。
- **字体**：使用系统字体栈，英文场景优先 Inter / system-ui。
- **阴影**：分层微阴影（sm / md / lg），避免大面积重阴影。
- **图标**：用 Lucide React 替换 emoji，提升专业感；仅在分类图标保留 emoji 作为趣味元素。

### 3.2 布局升级

- **可折叠侧边栏**：默认显示，支持收起为图标栏，释放主内容区宽度。
- **顶部栏精简**：搜索框居中放大，统计信息移至侧边栏或底部浮动面板。
- **主内容区**：
  - 卡片网格改为瀑布流或统一高度网格。
  - 增加列表视图切换（紧凑列表 vs 卡片网格）。
  - 空状态插画化。

### 3.3 交互升级

- **全局 Toast / Snackbar**：替换当前简单提示，支持操作撤销（如删除后撤销）。
- **骨架屏**：加载时显示骨架屏，避免空白闪烁。
- **拖拽排序**：分类管理、位置管理支持拖拽排序。
- **批量操作增强**：
  - 支持 Shift 连选。
  - 批量改分类 + 批量改位置 + 批量删除。
  - 批量操作栏改为底部浮动 Dock，不挤压内容区。
- **图片体验**：
  - 图片懒加载。
  - 点击查看大图（Lightbox）。
  - 本地图片支持直接拖拽/粘贴上传。

### 3.4 深色模式

- 基于 Tailwind `dark:` 前缀实现系统/手动切换。
- 图片区、卡片、弹窗均提供深色适配。
- 设置项增加「外观」选项：浅色 / 深色 / 跟随系统。

## 4. 组件库与工具选型

| 需求 | 推荐方案 | 理由 |
|------|---------|------|
| 图标 | `lucide-react` | 体积小、风格统一、Tree-shaking 友好 |
| 动画 | `framer-motion` | 声明式、性能优秀，但体积约 40KB gzip；若严格控体积可改用 CSS transition + `@headlessui/react` |
| 下拉/弹窗 | `@headlessui/react` 或自研 | Headless UI 无样式负担，体积可控 |
| 拖拽 | `@dnd-kit/core` | 功能完整、Tree-shaking 友好 |
| 日期选择 | 原生 `<input type="date">` | 避免引入日期库，保持体积小 |
| 图片 Lightbox | 自研简易组件 | 避免引入大图库 |

**体积控制建议**：
- 优先使用 CSS 动画和过渡，少用 JS 动画库。
- 若需要复杂页面切换动画，再引入 `framer-motion`，并在 Vite 中配置按需加载。
- 使用 `rollup-plugin-visualizer` 分析打包体积，定期清理未使用依赖。

## 5. 打包体积优化

- `electron-builder` 配置：
  - `files` 只保留 `dist/**/*` 和 `electron/**/*`。
  - 排除源码、测试、文档。
  - `asarUnpack` 只保留 `better-sqlite3`。
- 依赖优化：
  - 使用 `vite-plugin-bundle-analyzer` 检查 chunk。
  - 将大型第三方库拆分为独立 chunk 或按需加载。
- 资源优化：
  - 图片使用 WebP / 压缩。
  - 不使用自定义字体文件，依赖系统字体。

## 6. 分阶段实施计划

### 阶段一：基础设计系统（1 周）

1. 定义颜色、间距、字体、圆角、阴影 token。
2. 创建基础组件：`Button`、`IconButton`、`Input`、`Select`、`Modal`、`Card`、`Skeleton`。
3. 接入 `lucide-react`，替换关键 emoji 图标。
4. 实现浅色/深色模式切换。

### 阶段二：布局重构（1 周）

1. 可折叠侧边栏。
2. 顶部栏精简 + 搜索强化。
3. 卡片网格 / 列表视图切换。
4. 底部浮动批量操作 Dock。

### 阶段三：交互动效（1 周）

1. 页面切换、弹窗、Toast 动效。
2. 骨架屏加载状态。
3. 图片 Lightbox。
4. 分类/位置管理拖拽排序。

### 阶段四：打磨与体积优化（3-5 天）

1. 全链路手动测试。
2. 打包体积分析 + 裁剪。
3. 构建 Windows 便携版并验证。
4. 更新 README 与操作手册。

## 7. 验收标准

- 无控制台报错、无功能回归。
- 浅色/深色模式切换流畅。
- 便携版体积相较 V1 不增长超过 15%。
- 主要操作（添加、编辑、删除、批量操作、导入导出）路径不超过 3 步。

## 8. 风险提示

- 引入动画库会明显增加打包体积，建议先实现 CSS 版本，必要时再升级。
- 深色模式需要全量检查所有硬编码颜色，避免遗漏。
- 可折叠侧边栏需同步更新响应式断点，确保小屏可用。
